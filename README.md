# 卡口車牌

出入口卡口鏡頭走 SDK 埠 8000 布防。網頁開在 8123，看原始車牌；發布規則可以把 JSON 改完再 POST 到別的位址。

## 放 SDK

海康設備網路 SDK，Linux 64 位元版，解壓後放到 `sdk/`。需要的檔案寫在 `sdk/請把SDK放這裡.txt`。`libHCAlarm.so` 在 `HCNetSDKCom` 裡，布防靠它。

## 啟動

```bash
docker compose up --build
```

瀏覽器開 http://localhost:8123

1. 鏡頭頁填 IP、帳號、密碼，埠維持 8000，按儲存再按布防。
2. 車過閘口後，過車結果頁會出現車牌、車道、方向和圖片。
3. 發布規則頁填對方的 HTTP 位址，以及要送出的 JSON。`{{plate}}` 這類會換成這一筆的欄位，寫死的字（例如 `"gate": "入口1"`）會原樣送出。

網頁上的紀錄保持鏡頭原始內容。轉發用的是模板產生的另一份。

鏡頭要先開啟車牌抓拍，並允許上傳中心。容器要路由得到鏡頭 IP。

若車牌有了、圖片是空的，多半是 SDK 對齊和這支程式不一樣。把回調裡的 `reportedSize` 記下來，並用環境變數 `HIKSDK_LOG=1` 開 SDK 日誌後再看。
